# Official D-FLY Documentation 

## 1 How to compile the program ?

* On Linux you can use g++ available with GCC or clang++ available with Clang. Personally, I use clang++ because it's faster and i prefer it for debugging

* On FreeBSD / NetBSD you can use g++ and clang++

* On macOS you can use g++ and clang++

* On Windows you can use Visual Studio


## 2 How does the notation system works ?

The notation of a version follows the semantic versioning pattern X.X.X (Alpha | Beta)

The first digit refer to the major version of the release. Example: 1.0.0 = Version 1

The second digit after refer to the minor version of the release. Example: 1.1.0 = Version 1 + some extras

And the last digit refers to fixes done in the program. Example: 1.1.2 = Version 1 + some extras + fixed 2 times
